## 为什么可以判断程序正确

1. 所有计算使用精确分数，不依赖浮点数。
2. 每个生成表达式都会递归检查所有子表达式。
3. 去重规则同时覆盖交换律和题目要求的树结构区别。
4. 生成文件会被重新解析，确保输出格式可读。
5. 判分和题目计算复用同一个表达式求值模块。
6. 命令行测试覆盖生成、批改、错误参数和文件输出。
7. 10000 道题可以进行独立性能和重复性验证。
